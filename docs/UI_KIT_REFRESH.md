# UI-кит: изменения из Figma, 18.11.2026

Источник: страница «Проект» Figma, файл Zt53vIZnK6OY4tEvSRBN9C. Данные снимались из мастер-компонентов, а не старых экземпляров на страницах.

## Компоненты и изменения

1. block_Header (24:302): Desktop Closed/Opened, Mobile Closed/Opened/Opened (2). Два функциональных экрана мобильного меню, 390px × 880px в Figma.
2. button_Basic (24:643): 77 вариантов; размеры Solid/Linear S=12px/38px, M=14px/50px, L=16px/60px. Большая текстовая кнопка 32px теперь XL; текстовая L=28px; текстовая XS=12px; Text (Latex) S=14px и стрелка; Text (Bold) L с иконкой 20px.
3. svg_Socials (24:1237): экспортированы оригинальные SVG Instagram/Telegram/YouTube 20px; старые 24px сохранены.
4. button_Socials (24:1246): Desktop 48×48, Mobile 40×40, состояния Default/Hover. Реализовано в SocialButton.astro.
5. button_Menu (204:13130): размеры 36×36, Default/Pressed/Opened/Pressed(2), точные burger и close SVG.
6. icon_Arrow_Latex (24:640/24:641): мастер-компонент реально **18×18**. В пользовательском перечне пункт 7 называет стрелку «24px», но её обновлённый мастер-компонент — 18px, поэтому реализована геометрия из Figma. Старая ссылка на файл arrow-latex.svg сохранена.
7. icon_Arrow (24:824): добавлены оригинальные Up 20px, Up 14px (в исходнике название варианта «16 px», но размер его рамки 14×14), Left 14px.
8. element_Button (127:12549): Desktop 240×182, Mobile 166×116, нормальный и hover состояния, размер текста 16px/12px, letter-spacing 0; реализовано в ServiceMenuItem.astro.
9. frame_Discount (208:13996): Desktop 1470×32, Mobile 390×57. На Desktop центрирование, на Mobile вертикальная композиция.
10. block_Footer (24:342): Desktop 1470×640, Mobile 390×1041. Обновлена responsive-композиция с 40px социальными кнопками и шириной содержимого 340px.

## Функциональность

- Desktop Header «Услуги»: раскрытие по hover, click, focus/keyboard, Escape; пять реальных ссылок на услуги. Меню не раскрывается на mobile.
- Mobile Header: кнопка 36px, основное меню 28px, подменю услуг (2×2+1, 166×116/340×116), иконки соцсетей 20px, CTA, Escape, возврат фокуса и блокировка прокрутки под меню.
- Общая база кнопок Button/ActionLink без дублирования, добавлены типы text, text-bold, text-latex, xl/xs, направление стрелки. Старые размеры S/M/L сохраняют работу текущих страниц.
- Footer c 40px mobile-кнопками соцсетей, верхними контактами, навигацией, юридическими ссылками. Неподтверждённые адреса соцсетей не были придуманы; нет активных пустых ссылок.
- Все изображения в меню взяты из ранее сохранённых assets/figma, 9 новых/обновлённых пиктограмм — SVG-экспорт оригинальных Figma-узлов.
