## Yandex Maps

- Компонент: src/components/blocks/YandexCityMap.astro.
- При наличии PUBLIC_YANDEX_MAPS_API_KEY загружается JavaScript API v3 и показывается схема города через YMap и YMapDefaultSchemeLayer.
- Ключ нужно выпустить в кабинете Yandex Maps API и ограничить по HTTP Referer. Ключ браузерного JS API публичен, в production нужно разрешить домен сайта; для предпросмотра при необходимости localhost.
- В GitHub Actions repository variables можно задать YANDEX_MAPS_API_KEY, workflow development-check.yml передаст его в PUBLIC_YANDEX_MAPS_API_KEY. Production workflow должен сделать то же самое при будущем включении публикации.
- Без ключа и при ошибке API показывается интерактивный Yandex Map Widget (iframe) для городского обзора, а также ссылка на городскую карту.
- Центр — Витебск, долгота 30.1844, широта 55.1964 (по UNGEGN), масштаб 11. Не адрес, не местоположение офиса.
- Нет маркера, маршрута, карточки организации и вымышленного адреса. Пользователю поясняется, что адрес будет указан позже.
- После получения адреса: согласовать его публичность, добавить реальную точку и только затем обновить центр/zoom/маркер.
