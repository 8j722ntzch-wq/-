## Расширенная библиотека

- `npm run build:kit` успешно собирает `dist-kit/__ui/index.html`.
- Рабочий предпросмотр: http://127.0.0.1:4324/__ui/ .
- В браузере проверены загрузка шести оригинальных иллюстраций, карточки и окно заявки.
- Проверены обязательное имя, некорректный короткий телефон, валидный демонстрационный ввод, отсутствие ложного подтверждения отправки.
- Проверены открытие dialog, Escape, возврат фокуса и отдельное демонстрационное окно подтверждения.
- По последнему указанию пользователя проверки узких экранов прекращены. В CI оставлены десктопные ширины 1366 / 1470 / 1920. Мобильная приёмка ожидает макета.
- В исходниках синхронизирована актуальная конфигурация development, включая @types/node и Playwright. В локальном node_modules эти пакеты ещё отсутствуют; npm registry недоступен из shell. Полный check и регрессия выполняются существующим GitHub Actions.
- Текущий расширенный CI-прогон: ожидается после сохранения исходников в development.
