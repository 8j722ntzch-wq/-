## Что исправлено по результатам запусков

- Отсутствовали типы Node для строгой проверки конфигурации — добавлен @types/node и обновлён lock.
- В импортах Fontsource были несуществующие latin.css/cyrillic.css вариативных пакетов — заменены на wght.css, лицензии сохранены.
- Тест disabled checkbox ошибочно ожидал enabled при locator.click — заменён реальным pointer-нажатием по видимой подписи с проверкой сохранения выключенного состояния. Компонент не изменялся для обхода проверки.

Первичная подготовка lock выполнялась отдельным job с правом записи; после сохранения lock этот job удалён. Действующий workflow имеет только contents:read, npm ci и не публикует сайт. Пользовательский компьютер не используется для установки/проверок. Предыдущий локальный DNS-блок больше не блокирует облачную сборку.
