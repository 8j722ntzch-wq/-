## Архитектура

Статический Astro; HTML-компоненты и CSS, без React/Vue/Tailwind.
Токены → UI → составные блоки → секции → страницы. Собраны UI и составные блоки; актуальный перечень — COMPONENT_MAP.md.
Страница `/__ui/` внедряется интеграцией только для dev или явной тестовой сборки.
Исходник витрины лежит вне `src/pages`. `dist-kit` не является production-артефактом.

Технологический выбор: Astro 7.4.12, @astrojs/check 0.9.12; версии проверены по официальным источникам.
https://docs.astro.build/en/upgrade-astro/
https://www.npmjs.com/package/@astrojs/check
Node: 22.23.4 зафиксирован в .nvmrc и используется GitHub Actions. Зависимости установлены по сохранённому package-lock.json. Astro check, сборка витрины и 60 браузерных автотестов проходят. Inter/JetBrains Mono подключены через wght.css; лицензии OFL сохранены в public/licenses. Визуальная точность шрифтов по Figma ещё не принята.
